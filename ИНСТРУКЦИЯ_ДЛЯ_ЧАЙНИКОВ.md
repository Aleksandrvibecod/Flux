# Flux - Инструкция в 3 шага (для чайников)

Твой бот падает потому что нет ключей. Сделай 3 вещи:

## ШАГ 1: Почини БАЗУ (backend)

1. Открой railway.com -> проект hopeful-cooperation -> нажми на КРАСНЫЙ сервис Flux (где написано CRASHED)
2. Вверху нажми VARIABLES
3. Нажми + New Variable и вставь ПО ОДНОЙ эти 7 строчек:

```
SUPABASE_URL=https://xxx.supabase.co
SUPABASE_ANON_KEY=eyJ....
SUPABASE_SERVICE_KEY=eyJ....  <- бери service_role, не anon!
GEMINI_API_KEY=sk-or-v1-...
GEMINI_BASE_URL=https://openrouter.ai/api/v1
GEMINI_MODEL=google/gemini-2.0-flash-lite-preview-02-05:free
TELEGRAM_BOT_TOKEN=твой токен от @BotFather
```

Где взять SUPABASE_URL? -> supabase.com -> твой проект -> Settings (шестеренка) -> API -> Copy URL и service_role key

4. Потом нажми Settings -> Source -> Root Directory -> напиши `backend` -> Save
5. Нажми фиолетовую кнопку Deploy вверху

Если все ок - в логах будет `backend on 3000` и CRASHED пропадет.

## ШАГ 2: Почини БОТА (2й сервис)

1. В Railway нажми + New Service -> GitHub Repo -> выбери Flux
2. Сразу Settings -> Root Directory -> напиши `bot` -> Save -> Deploy
3. Variables -> добавь 3 строчки:

```
TELEGRAM_BOT_TOKEN=твой токен от @BotFather
BACKEND_URL=https://xxx.up.railway.app  <- скопируй из ШАГА 1, вкладка Settings -> Networking -> Generate Domain
MINIAPP_URL=https://твой-vercel.app  <- пока оставь так, поменяем на Шаге 3
```

## ШАГ 3: Мини-приложение (сайт)

1. Открой vercel.com -> Add New Project -> Import Flux
2. ВАЖНО: нажми Edit рядом с Root Directory и выбери `miniapp` (если не выбрать - будет ошибка Nx workspace как на скрине FAILED)
3. В Environment Variables добавь:

```
VITE_BACKEND_URL=https://xxx.up.railway.app (тот же что в Шаге 2)
```

4. Нажми Deploy -> скопируй ссылку вида https://flux-xxx.vercel.app
5. Вернись в Railway -> bot -> Variables -> поменяй MINIAPP_URL на эту ссылку -> Restart
6. В Телеграм -> @BotFather -> /mybots -> твой бот -> Menu Button -> вставь ссылку https://flux-xxx.vercel.app

Готово! Напиши боту /start
